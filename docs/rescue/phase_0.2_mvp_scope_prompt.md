# Prompt Phase 0.2 — Chặn phạm vi MVP nếu sắp deadline

You are a product/engineering lead for a deadline rescue.

Based on the inventory, define a MINIMUM SURVIVAL SCOPE.

Requirements:
- The app must be demoable.
- The app must not crash.
- The app must allow: login, view orders, open one order detail, view route stops check-in if stable, capture photo/signature if stable.
- Disable or hide unstable advanced modules if needed: recurring, expense, timesheet, stock, complex routing.

Output:
1. Must-work flows
2. Should-work flows
3. Disable-temporarily flows
4. Exact screens/routes to keep
5. Exact screens/routes to redirect or hide
6. Risk list
